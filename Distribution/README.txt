VcabTone 1.2.0
==============

声のための EQ とディエッサーです。遅延は 0 です。
対応: Windows（64bit）

■ 中身
  VcabTone.exe   単体で動く EXE 版
  VcabTone.vst3  VST3 プラグイン

■ 使い方
  EXE 版: VcabTone.exe を実行し、「オーディオ設定」ボタンで
          入力と出力のデバイスを選びます。
  VST3 版: VcabTone.vst3 をフォルダごと
          C:\Program Files\Common Files\VST3 にコピーし、DAW で読み込みます。
  ボイスチェンジャーの後ろ、コンプ・リミッター・ゲートの前に置く想定です。

■ 注意
  ・ヘッドフォンで使ってください。スピーカーだとハウリング（大きな音）が
    起きることがあります。EXE 版は起動してすぐ音が出ます。
  ・ローカットの初期値は 80Hz です。ボイスチェンジャーで声を高くした後なら、
    100〜120Hz に上げると、低い雑音（ハムなど）をより深く削れます。
  ・署名をしていないため、初回に「PC が保護されました」と出たら
    「詳細情報」→「実行」を押してください。
  ・EXE 版の設定は %APPDATA%\VcabTone に保存されます。

■ 画面
  グラフは、入力（青）と出力（橙）のスペクトルと、EQ の特性（黄の線。右の目盛り）です。
  EQ の点はドラッグで動かせます（ホイールで、中域は幅、低域・高域は増減。
  ダブルクリックで 0 に戻す）。
  緑の帯と紫の帯は、ディエッサーが見ている下の帯域（判定の下端〜境目）と
  上の帯域（境目〜判定の上端）です。境目は実線、両端は点線で引いています。
  赤の塗りはいま削っている量です。
  「削り量」のメーターの左のランプは、サ行を見つけたときに灯ります。
  「削った音だけを聞く」で、ディエッサーが削った音だけを聞けます。
  詳しい説明は、つまみや項目にマウスを乗せると出ます。
